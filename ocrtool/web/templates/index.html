OCR a folder of documents

Point this at a folder. It reads every PDF and image inside it — page by page, on this machine, with nothing sent anywhere — and writes a searchable copy of each document, its text, and a per-page report into an output folder you choose.

1Where are the documents?

PDF, PNG, JPG, TIFF, BMP, WEBP, GIF

Drop files or a folder here

A browser can only hand over copies, so uploads are written into <output>/_uploads/ first. For a folder already on this machine, the other tab is faster and uses no extra disk.

2Where should the results go?

Every document produces three files — .pdf (the same pages, now searchable), .txt (the text), and .json (text, confidence, and word positions) — sorted into pdf/, txt/ and json/, each keeping your subfolder names inside it. Page pictures go in _previews/, and each run's report and pages.csv go in _runs/.
